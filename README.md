# সোনার বাংলা উচ্চ বিদ্যালয় (Sonar Bangla High School)

একটি আধুনিক এবং প্রতিক্রিয়াশীল (responsive) বিদ্যালয় ব্যবস্থাপনা ও তথ্যভিত্তিক পোর্টাল।

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Features)

- **হোম ও একাডেমিক তথ্য**: বিদ্যালয়ের পরিচিতি, নোটিশ বোর্ড, একাডেমিক ক্যালেন্ডার এবং ফলাফল।
- **ভর্তি কার্যক্রম (Admission Portal)**: অনলাইন ভর্তি আবেদন ফর্ম এবং ভর্তির নীতিমালা।
- **ফলাফল যাচাই (Result Portal)**: শিক্ষার্থীদের রোল/আইডি ও শ্রেণি অনুযায়ী রেজাল্ট দেখার সুবিধা।
- **শিক্ষক ও পরিচালনা পর্ষদ**: শিক্ষক ও গভর্নিং বডির তালিকা ও তথ্যাদি।
- **অ্যাডমিন প্যানেল**: নোটিশ, শিক্ষার্থী, শিক্ষক, রেজাল্ট এবং সেটিংস পরিচালনার জন্য ড্যাশবোর্ড।
- **ডার্ক/লাইট মোড**: আধুনিক থিম সাপোর্ট।

## 🛠️ প্রযুক্তি (Tech Stack)

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Routing**: React Router v7
- **Charts & Animation**: Recharts, Framer Motion
- **Build Tool**: Vite

## 💻 স্থানীয়ভাবে চালানোর নিয়মাবলী (Local Setup)

১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

২. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```

৩. প্রোডাকশন বিল্ড তৈরি করতে:
```bash
npm run build
```
